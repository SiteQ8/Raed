رائد

نسخة عربية مفتوحة من سجل الثغرات الأمنية المعلنة، تقرأ سجلات برنامج CVE كما تنشرها الجهات المرقّمة ثم تعرضها بالعربية وتتجدد كل ساعة.

المشروع مستقل ولا يتبع برنامج CVE أو مؤسسة MITRE أو وكالة CISA، والمرجع الرسمي لكل سجل هو موقع cve.org.

الأقسام

  • أحدث الثغرات
  • الثغرات المستغلة فعلياً
  • النشرة الأسبوعية
  • نحو جهة ترقيم عربية
  • نشرات رائد
  • أبلغ عن ثغرة
  • قاعة الشرف
  • الأسئلة الشائعة
  • البيانات المفتوحة

المصادر

  • قائمة سجلات CVE
  • قائمة CISA للثغرات المستغلة
  • نظام EPSS من FIRST
  • تصنيف نقاط الضعف CWE
  • الشيفرة المصدرية

CVE® علامة تجارية مسجلة لمؤسسة MITRE، وتُستخدم سجلات البرنامج وفق شروط الاستخدام التي تتيح نسخها وتوزيعها مع الإشارة إلى المصدر، أما الشيفرة فمنشورة برخصة MIT.
