نشرات رائد

هنا تصدر النشرات الأمنية التي يكتبها «رائد» بنفسه عن الثغرات التي يُبلّغ بها في البرمجيات والخدمات العربية، ولكل نشرة وصف عربي ووصف إنجليزي وسجل CVE كامل يُرفع كما هو إلى قائمة البرنامج.

  • لم تصدر نشرة بعد، وستكون أول نشرة لأول ثغرة تبلغنا بها في برمجية أو خدمة عربية.

كيف تصدر النشرة

يصل البلاغ وفق سياسة الإفصاح، ثم يتحقق «رائد» منه وينسق مع المورّد حتى يصدر الإصلاح، وبعد ذلك تُنشر النشرة هنا بالعربية أولاً ومعها السجل بصيغة CVE JSON 5، أما الرقم فيُطلب اليوم من الجهة المرقّمة المختصة ريثما يُقبل طلب «رائد» ليرقّم بنفسه، والتفاصيل في صفحة الطلب.

وتتيح صيغة السجل الرسمية أن يحمل السجل أوصافاً بأي لغة ما دام بينها وصف إنجليزي، لذا تحمل سجلات «رائد» وصفاً عربياً كاملاً يظهر في قائمة CVE نفسها إلى جانب الإنجليزي.

رائد

نسخة عربية مفتوحة من سجل الثغرات الأمنية المعلنة، تقرأ سجلات برنامج CVE كما تنشرها الجهات المرقّمة ثم تعرضها بالعربية وتتجدد كل ساعة.

المشروع مستقل ولا يتبع برنامج CVE أو مؤسسة MITRE أو وكالة CISA، والمرجع الرسمي لكل سجل هو موقع cve.org.
