الجهات المرقّمة

الجهة المرقّمة مؤسسة يأذن لها برنامج CVE بحجز أرقام الثغرات ونشر سجلاتها داخل نطاق محدد، كأن يرقّم المورّد ثغرات منتجاته أو يرقّم فريق الاستجابة الوطني ما يُبلّغ به.

لا توجد حتى اليوم جهة مرقّمة واحدة في الدول العربية، لذا تذهب ثغرات المنتجات والخدمات العربية إلى جهات في الخارج لترقيمها، وهذا طريق جهة ترقيم عربية بشروطه ونماذجه، وهذا طلب «رائد» ليكون أولها.

رائد

نسخة عربية مفتوحة من سجل الثغرات الأمنية المعلنة، تقرأ سجلات برنامج CVE كما تنشرها الجهات المرقّمة ثم تعرضها بالعربية وتتجدد كل ساعة.

المشروع مستقل ولا يتبع برنامج CVE أو مؤسسة MITRE أو وكالة CISA، والمرجع الرسمي لكل سجل هو موقع cve.org.
