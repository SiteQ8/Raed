# نشرات رائد

هنا يكتب «رائد» نشراته الأمنية عن الثغرات التي يُبلّغ بها أو يكتشفها، وكل نشرة ملف واحد يحمل سجل CVE كاملاً بصيغة JSON 5 ليُرفع كما هو إلى خدمات CVE حين يصبح «رائد» جهة مرقّمة، ثم يبني الموقع منه صفحة عربية في `/advisories/<المعرّف>/`.

## شكل الملف

اسم الملف هو المعرّف المحلي مثل `RAED-2026-0001.json`، ومحتواه:

```json
{
  "raed": {
    "id": "RAED-2026-0001",
    "status": "draft",
    "published": "2026-11-01",
    "titleAr": "عنوان النشرة بالعربية"
  },
  "record": { "...": "سجل CVE كامل بصيغة JSON 5.2" }
}
```

قيم `status` ثلاث، فالمسودة `draft` لا تُنشر، و`requested` تعني أن الرقم طُلب من الجهة المرقّمة المختصة، و`published` تعني أن السجل نُشر في قائمة CVE.

## قواعد تفرضها الاختبارات

- يتحقق كل سجل من المخطط الرسمي للصيغة في `tests/schema/`، وهو منشور برخصة CC0.
- يحتوي حقل `descriptions` على وصف إنجليزي لأن المخطط يشترطه، وعلى وصف عربي بالرمز `ar` لأن «رائد» يشترطه.
- يتبع الوصف العربي قاعدة الكتابة في الموقع كله، أي نقطة واحدة في نهاية كل جملة وربط الأجزاء بأدوات العطف.

انسخ [`_template.json`](_template.json) لتبدأ، فالملفات التي تبدأ بشرطة سفلية لا تُنشر.
