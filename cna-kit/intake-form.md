# حقول استقبال البلاغ

كل حقل هنا يقابل حقلاً في سجل CVE بصيغة JSON 5، لذا يكفي البلاغ المكتمل لكتابة السجل دون مراسلات إضافية.

| الحقل | يقابله في السجل | إلزامي |
|---|---|---|
| اسم المبلّغ أو الاسم المطلوب للنسبة | `credits[].value` | لا |
| بريد المبلّغ | لا يُنشر | نعم |
| المورّد | `affected[].vendor` | نعم |
| المنتج | `affected[].product` | نعم |
| الإصدارات المصابة وأول إصدار يصلحها | `affected[].versions[]` | نعم |
| نوع الضعف إن عُرف | `problemTypes[].descriptions[].cweId` | لا |
| وصف الثغرة وطريقة استغلالها | `descriptions[]` | نعم |
| الأثر | `impacts[]` و`metrics[]` | نعم |
| خطوات إظهار الثغرة وإثبات المفهوم | لا يُنشر قبل الإصلاح | نعم |
| مراجع عامة إن وُجدت | `references[]` | لا |
| هل الثغرة معلنة أو مستغلة فعلياً | يحدد موعد النشر | نعم |

## صيغة بريد مقترحة

```
الموضوع: بلاغ عن ثغرة في {PRODUCT}

المورّد:
المنتج:
الإصدار:
نوع الضعف:
الوصف:
خطوات إظهار الثغرة:
الأثر:
هل الثغرة معلنة أو مستغلة:
الاسم المطلوب للنسبة:
```
